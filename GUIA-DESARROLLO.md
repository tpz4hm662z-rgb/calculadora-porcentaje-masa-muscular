# 🚀 GUÍA DE DESARROLLO OFICIAL

# Herramientas360

Versión 1.0

---

# Filosofía

Herramientas360 no desarrolla simples calculadoras.

Desarrolla herramientas profesionales, rápidas, útiles, intuitivas y optimizadas para ofrecer la mejor experiencia posible al usuario.

Cada herramienta debe aportar valor real.

La prioridad siempre será la calidad antes que la cantidad.

---

# Objetivo

Construir el mayor portal de herramientas gratuitas en español.

Cada nueva herramienta debe ser mejor que la anterior.

---

# Estructura obligatoria

Todo proyecto nuevo debe contener:

```
index.html

css/
style.css

js/
script.js

README.md

CHANGELOG.md

robots.txt

sitemap.xml
```
