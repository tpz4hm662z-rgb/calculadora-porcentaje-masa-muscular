# Calculadora de Porcentaje de Masa Muscular Pro

Herramienta de Herramientas360 para estimar el porcentaje de masa muscular y ofrecer una interpretación orientativa a partir de datos corporales.

URL oficial: https://tpz4hm662z-rgb.github.io/calculadora-porcentaje-masa-muscular/

## Uso

Abre `index.html` en un navegador o sirve la carpeta con un servidor estático.

## Estructura

- `index.html`: interfaz, contenido y metadatos.
- `css/style.css`: estilos responsive.
- `js/config.js`: configuración y URL oficial.
- `js/core.js`: validaciones y utilidades comunes.
- `js/script.js`: cálculo e interpretación de resultados.

## Alcance

El resultado es una estimación y no sustituye una medición clínica de composición corporal.
